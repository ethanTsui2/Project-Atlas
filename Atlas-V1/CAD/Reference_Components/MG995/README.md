# MG995 Servo Reference

The MG995 servo is used for the three main Atlas V1 joints:

- base rotation
- shoulder pitch
- elbow pitch

The reference model in this folder was used for:

- servo packaging
- mounting-hole placement
- joint-clearance checks
- horn alignment
- assembly interference analysis

## Important Note

MG995 dimensions can vary slightly between manufacturers. All printed mounting interfaces should be verified using the physical servos before full production printing.
